			VISUAL STUDIO CODE CON GIT BASH
En el panel de control textualmente se dice cuanta RAM quieres 
en cuantos Quantums hace cada proceso y que estrategia quieres usar
Para compilar es solo guardar el cambio en scr/main.c
despues se ejecuta en la terminal de VS code 
	gcc -Iinclude src/*.c src/algorithms/*.c src/memory/*.c src/scheduler/*.c -o bin/main.exe
para compilar todo en un mismo bloque con el bin/make.exe

Finalmente se ejecuta 
	python scripts/benchmark.py
Para crear el archivo .csv que puede ser leido de los valores registrados

y luego se ejecuta 
	python scripts/graphs.py
Para que python lea el archivo .csv y cree una tabla con ello
